# RepoSherlock Frontend Prototype

## Goal
Build a polished, self-contained frontend prototype that tells the complete RepoSherlock story using realistic mock data only.

## Experience
- Create a cinematic entry scene and playful mock sign-in with responsive character reactions.
- Build the clickable journey: dashboard → repository selection → indexing → issue selection → investigation progress → workspace.
- Make the investigation workspace the centerpiece, with hypothesis confidence, a prominent WHY interaction, evidence drawer, evidence map, code inspection, history timeline, impact map, and ordered fix plan.
- Add mock settings, pricing, and polished loading/error/empty/success examples without any real account, payment, repository, or AI connection.

## Visual system
- Use warm off-white and cream foundations with purposeful lavender, blue, peach, mint, coral, violet, and yellow accents.
- Combine a modern sans-serif UI with monospaced code text.
- Create lightweight illustrated developer characters and repository artifacts with CSS/SVG; use calm parallax and restrained transitions.
- Preserve strong contrast, visible focus states, keyboard access, and reduced-motion support.

## Structure
- Centralize the mock data and reusable UI patterns.
- Keep every interaction local to the browser and clearly presented as a prototype.
- Adapt the workspace from three columns on desktop to two columns on tablet and sheets/bottom navigation on mobile.

## Validation
- Verify the complete click path, key interaction states, desktop presentation, and mobile layout.
- Confirm the project has no backend, API, authentication, billing, or external-service integration.
